# DailyMapLine 로컬 기술 시제품

서울 시청 주변의 작은 공개 지도와 합성 위치 노드로 다음 흐름을 실행한다.

1. MapLibre GL JS로 로컬 지도를 표시한다.
2. 노드 5개를 도로 그래프 위의 브랜치 4개로 연결하고 로컬에 저장한다.
3. 메인 지도에서 브랜치 양옆 50m의 색을 걷는다.
4. 같은 기록으로 9:16 이동 영상을 생성하고 파일로 저장한다. 영상에는 색 걷기가 없다.

## 실행

Node.js와 npm이 필요하다. 이 환경에서는 Node 22.23.3으로 확인했다.

```sh
cd /Users/kimhwi/Documents/ChatGPT/DailyMapLine/prototype
npm ci
npm run build
npm start
```

브라우저에서 http://127.0.0.1:4173 을 연다. 시험 노드로 브랜치를 만든 뒤 영상 만들기를 누르고 완료되면 영상 저장을 누른다. Chrome에서 MP4로 출력했으며, 다른 브라우저는 지원 여부에 따라 WebM 또는 오류 안내를 사용한다.

개발용 HTTP 프로세스는 이 컴퓨터의 정적 파일만 제공한다. 서비스용 백엔드나 위치 업로드 기능이 아니다. 지도·경로·라이브러리는 로컬에 준비되어 있고 실행 중 외부 지도 서버를 사용하지 않는다. 라이브러리 최초 설치와 지도 원본을 다시 받는 작업에는 인터넷이 필요하다.

## 데이터와 출처

- 지도·길: OpenStreetMap contributors, ODbL 1.0. 출처: `public/data/metadata.json`.
- 원본: 공개 OSM API의 작은 bbox 추출물. 개인 위치가 아니며 기여자 계정 메타데이터는 파생 파일에 남기지 않는다.
- 상세 데이터: 약 680KB GeoJSON과 약 171KB 길 그래프. 다운로드한 원본 파일의 크기와 파생 파일의 크기는 다르다.
- 기록 입력: `public/sample.json`의 공개 장소 좌표 5개. 날짜와 순서만 있으며 노드별 시각은 없다.
- 저작자 표시와 라이선스: https://www.openstreetmap.org/copyright 및 `public/THIRD-PARTY-NOTICES.txt`.

일반 지도 데이터가 필요할 때 직접 API에서 넓은 지역을 반복 내려받는 구성으로 확대하지 않는다. 상용 데이터 공급·업데이트·비용은 별도 과제다.

## 구현과 제한

길 연결은 지역 그래프에서 A*로 계산한 최소 거리의 **도로망 경로 추정**이다. 노드를 곧장 잇는 직선이 아니지만 실제로 이동했던 길을 복원한다는 뜻도 아니다. 통행 방향·고도·이동 수단·자동차/보행 가능성을 판정하는 엔진은 구현하지 않았다. 실제 제품의 경로 엔진을 확정한 것으로 간주하지 않는다.

노드가 길에서 80m보다 멀거나 길이 연결되지 않으면 오류를 표시한다. 지도에 길이 없다고 확정한 뒤 직접 연결하는 기능은 이 작은 도로 실험에서 구현하지 않았다. 데이터 부재를 실제 길 부재로 바꾸지 않는다.

이 시제품은 브라우저의 localStorage에 시험 기록을 보관한다. 앱의 저장 기술, 압축 백업, 월 달력·삭제 정책, iOS·Android 앱은 아직 구현하지 않았다. 사용자 위치를 수집하거나 권한을 요청하지 않는다.

영상은 경로를 일정한 속도로 따라가며 현재 실험에서는 1km당 1초(이전 1km당 5초 대비 5배속)로 재생한다. 방향각은 길의 인접 구간 벡터를 비교하며 25도 이상에 표시한다. 30fps와 720×1280은 이번 기술 실험의 출력 규격이다. 최종 앱의 해상도와 프레임률 확정이 아니다.

축척은 360 CSS px 너비의 화면에서 1.5cm를 약 57 CSS px로 환산한 기준을 출력에 적용했다. 720px 영상에서는 막대가 114px이다. 실제 기기의 물리적 1.5cm를 보장하지 않는다. 작은 지도 범위 때문에 영상의 넓은 축척에서는 주변이 비어 보이며 영상 안에도 그 범위를 알린다. 지도를 확대해 기존 축척을 임의로 바꾸지 않았다.

추가 주변 지도 공급처 조회에서 Protomaps 메타데이터 요청은 403, Overpass 요청은 TLS 연결 실패가 발생해 보완되지 않았다. 해당 데이터·도구를 결과에 포함하지 않았다.

## 검증

```sh
npm test
npm run test:browser
```

브라우저 검증은 로컬 서버를 실행한 상태에서 설치된 macOS Google Chrome을 사용한다. 실행 파일 경로는 `tests/browser.mjs`에 명시되어 있다. 실제 지도·브랜치 생성, 새로고침 후 기록 복원, 영상 생성과 다운로드를 확인한다. 출력 영상의 크기·길이, 페이지 오류와 외부 요청도 기록한다. 영상 렌더링 중 필요한 로컬 요청은 허용하며 외부 요청은 기록·차단한다.

`outputs/`에 스크린샷·영상·브라우저 결과 JSON이 남는다. 배터리와 실제 모바일 백그라운드 기록은 합의대로 실측하지 않았다. 서울 시청 시험 성공을 전 세계 지도·모바일 성능 검증으로 일반화하지 않는다.
