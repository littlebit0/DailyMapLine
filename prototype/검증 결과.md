# 기술 시제품 검증 결과

## 실행 결과

- 공개 OSM 지도 데이터와 MapLibre GL JS로 서울 시청 주변 지도를 표시했다.
- 합성 기록 노드 5개를 길을 따라 브랜치 4개로 연결했다. 총 길이는 약 2.10km다.
- 메인 지도에서 브랜치 양옆 50m를 드러냈다. 버퍼 폭 계산과 화면을 확인했다.
- 노드별 시각 없이 날짜·좌표·순서와 브랜치를 브라우저에 저장하고 새로고침 후 다시 읽었다.
- 720×1280 MP4 파일을 생성·다운로드했다. 영상 길이는 10.54초이며, 1km당 5초로 계산한 목표는 10.48초다.
- 브라우저 검사 중 외부 네트워크 요청 0건, 페이지 스크립트 오류 0건이었다. 이미 로컬 데이터를 읽은 뒤 후속 HTTP 요청을 차단한 상태에서도 영상 생성·저장을 확인했다.
- 코어 검사 5개가 통과했다. 경로 간선 연결·왕복 순서, 연결 실패, 속도·축척 경계, 방향각 표시, 선 길이·버퍼를 다룬다.
- 390px 너비 화면에서 가로 넘침 없이 기록 생성이 동작했다. 모바일 운영체제 앱 검증은 아니다.

## 제한

브라우저 기술 시제품이며 iOS·Android 네이티브 앱은 아니다. 실제 위치 권한·백그라운드 기록·배터리는 실측하지 않았다. 서비스 서버나 위치 업로드는 없고 정적 파일을 제공하는 localhost 개발 프로세스만 사용한다.

A*로 길 그래프의 경로를 추정했으며 실제 이동을 복원하거나 이동 수단·통행 방향·접근 제한을 판정하지 않는다. 시험 입력만 사용한다. 길 부재가 확정된 구간의 직접 연결, 달력·삭제·압축 백업, 장거리 축소 전환의 실제 영상은 검증하지 않았다.

기본 축척은 유지했다. 상세 지도는 작은 지역만 포함하므로 영상에서 그 밖의 지역은 비어 보인다. 이를 영상에 표시했다. 추가 주변 데이터 조회는 Protomaps 메타데이터 403 및 Overpass TLS 연결 실패로 완료하지 못했으며 해당 데이터는 결과에 포함되지 않았다.

OSM 데이터의 라이선스와 소프트웨어 라이선스 고지를 보관했지만 전 세계 상용 지도 공급·영상 이용 조건을 모두 검토한 결과는 아니다.

## 후속 수정: 브랜치 주변만 드러내기와 5배속

폐회로 버퍼의 안쪽 빈 영역을 마스크에 보존하도록 수정했다. 브랜치에서 약 22m인 양쪽은 드러나고 약 67m인 안쪽과 폐회로 중앙은 계속 덮이는 회귀 검사를 통과했다. 코어 검사 총 6개 통과.

이번 속도 실험은 1km당 1초이며, 같은 약 2.10km 경로의 MP4는 2.16초로 생성·저장됐다. 목표 재생 길이는 2.10초이고 실시간 인코딩 종료에 따른 짧은 차이가 있다. 실행 중 외부 요청과 페이지 오류는 0건이었다. 이전 영상과 증거는 outputs/history/baseline-1km-5s/에 보관했다.
